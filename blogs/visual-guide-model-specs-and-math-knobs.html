A Visual Guide to Model Specs & Math Knobs

Do you need textbook proofs to pick, serve, or fine-tune a real LLM? No. About 80% of model selection and deployment is knowing what the spec sheet visually means—and the remaining 20% is visual intuition for the few math knobs that save you when something breaks.

The 80 / 20 Rule of Practical LLMs

Spec literacy (80%) tells you which model fits your GPU, latency budget, and task. Math-knob intuition (20%) tells you why fine-tuning spikes, why memory overflows at long contexts, and how to tune LoRA, KL penalties, and sampling cleanly.

1. Total vs. Active Parameters (Dense vs. MoE)

When a model card says 8B Dense, every single token passes through all 8 billion weights. When a model card has an A in its name—like 26B A4B (Mixture of Experts)—all 26B parameters must still sit in GPU memory (VRAM), but a tiny router wakes up only 4B active parameters per token.

The practical rule is simple: Total parameters determine VRAM; Active parameters determine speed.

2. Precision & Quantization (How Many Bits Per Weight?)

Every parameter is just a decimal number stored in GPU memory. Quantization shrinks how many bits represent each number—trading a tiny rounding error for 2× to 4× less VRAM and much faster token generation (because LLM decoding is bottlenecked by memory bandwidth).

3. Context Window, KV Cache & Grouped Query Attention

Two models with the exact same parameter count can have wildly different memory limits on long prompts. Every token in the prompt stores past Key & Value vectors (the KV cache) so the model doesn't recompute them from scratch.

Modern models shrink this bottleneck in two ways: Sliding Window (Local) Attention (each token only looks back at nearby tokens) and Grouped Query Attention (GQA) (multiple Query heads share one Key/Value cache).

4. Architecture Families & Training Stages

Remember Day 1's contract fθ : X → Y? The architecture family decides what can enter (X) and exit (Y), while the training stage decides how the model behaves out of the box.

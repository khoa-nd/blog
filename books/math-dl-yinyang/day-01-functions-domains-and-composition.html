Yin Yang · Ch. 1.2 (pp. 3–4), Ch. 2.2 & 2.7 (pp. 25, 37)

Functions, Domains, Codomains & Composition

Strip away the code and buzzwords: a deep-learning model is simply a tunable input-to-output rule (fθ : X → Y) built by plugging simple rules into each other like an assembly line.

Core Symbols: X, Y, x, θ, fθ(x), g ˆ f
Prerequisites: None (Day 1 starting point!)

1 · Visual Mental Model

Every Model Has Three Contracts: What Enters, What Tunes It, What Exits

Definitions 1.2.1 & 1.2.2
1. Why Codomain Y Matters

The same image input x needs a totally different Y depending on your task: [0,1] for binary yes/no, R^10 for 10 digits, or a token sequence for captions.

2. Input x vs. Knob θ

Observed data x is fixed by the example. Parameters θ are what training adjusts. Changing θ swaps out which function you're using.

3. Score ≠ Probability ≠ Label

From Ch. 2.2 (p. 25): real pipelines separate the raw score (sθ : X → R), the probability ([0, 1]), and the final hard label ({0, 1}).

Translating Yin Yang's Figures Into Plain English

Clipped from Book pp. 2–3

Book Figure 1.3 (p. 3): A parameterized model sends input x through fθ to produce prediction ŷ.

x
Blue Input Square → Domain X

Raw data converted into numbers (like pixel intensities). Fixed when making a prediction.

θ
Top 3 Dials → Parameters θ ∈ Θ

Each dial setting chooses one concrete function from the model family. In LLMs, there are billions of dials!

f
Teal Box → Architecture fθ

The fixed wiring blueprint of layers. Training does not rewire the box—it turns the dials.

ŷ
Green Bars → Output in Codomain Y

The prediction (scores/probabilities). Bottom orange gears compare ŷ to truth y and nudge the dials.

How Real Data Enters Domain X (Book Figure 1.2, p. 2)

A function needs numbers, not ink. So the book turns a handwritten "1" into a grid of brightness numbers, flattens it into one ordered list x, and keeps the true answer y = 1 beside it.

To make the math easy to check by hand, Chapter 1 shrinks that long list down to just two features: x = (0.20, 0.80).

4 · Stacking Layers = Function Composition

Defeating the "Right-to-Left" Notation Trap (g ˆ f)

Book p. 4 · Definition 1.2.3

Why this looks backwards: In math, L2 ˆ L1(x) means L2(L1(x)) — the layer closest to x (on the right!) runs first.

Interactive 2-Layer Pipeline: f(t) = (L₂ ˆ L₁)(t)
Step 1 · L₁ (Rightmost) 2t − 1
Affine stretch & shift
h₁ = 1.40
Step 2 · L₂ (Middle) max(0, h₁)
ReLU nonlinear gate
h₂ = 1.40
Step 3 · L₃ (Leftmost) 0.5·h₂ + 0.2
Final output score
ŷ = 0.90

Domain/Codomain Handshake: Notice that the output space of L1 must match the input space of L2. Try sliding t < 0.5 to see L2 clamp negative h1 values to 0!

5 · Quick Symbol Decoder

X → Y

Maps inputs in domain X into outputs in codomain Y.

θ ∈ Θ

All tunable knobs (weights + biases) inside allowed knob space.

fθ(x) = ŷ

Running input x through knob-setting θ yields prediction ŷ.

g ˆ f

Composition: do f first, then feed its output into g.

Why Composition Unlocks Day 10

Because a deep network is Lm ˆ … ˆ L1, training uses the Chain Rule to pass error signals backward layer by layer.

3-Check Modeling Rule (p. 4)

Before training, always check: (1) right input X, (2) right output Y, (3) rich enough function family {fθ}.
